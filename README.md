# USER MANAGEMENT 
This is a basic Node.js REST API built using the native http module and file system(fs)
Implemented a CRUD operation (GET,POST,PUT,DELETE) on user data stored in a JSON file

# FEATURES 
- Get all users
- Get user by ID
- Create new user
- Update existing user
- Delete user
- File-based data storage (users.json)

# How to run 
1. Install dependencies (if any): 
   npm install
2. Start server:
   npm start
or (with nodemon):
   npm run dev
